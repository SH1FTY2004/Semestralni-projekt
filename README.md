# Semestralni-projekt

Krátký popis:
Aplikace umožňuje vytvářet a spravovat databázi posilovacích cviků rozdělených podle svalových skupin. Uživatel si může zaznamenávat své tréninky, počítat odhadované 1RM (one-rep max), sledovat osobní rekordy. Program také vyhodnocuje, jak byly jednotlivé svalové partie zatíženy.

Klíčové cíle/funkce:

Databáze cviků rozdělená podle svalových skupin (např. prsa, záda, nohy, ruce, ramena)
Výpočet 1RM (Epleyho nebo Brzyckiho vzorec)
Ukládání tréninků a výsledků do souboru
Sledování osobních rekordů (PR)
Výpočet procentualní zátěže pro jednotlivé svaly v tréninku
